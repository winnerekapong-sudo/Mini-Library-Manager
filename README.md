# Mini Library Manager 📚

A simple JavaScript-based library management system that allows users to manage books in a library.

## Project Description

The Mini Library Manager is a small application built with JavaScript to practice working with arrays, objects, and functions. It allows users to add books, remove books, borrow books, return books, and search for books.

## Features

- Add a new book to the library
- Remove a book from the library
- Borrow available books
- Return borrowed books
- Search for books by title or author
- Display all books in the library
- Track book availability status

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

Each book is stored as an object containing:
- Book ID
- Title
- Author
- Availability status

JavaScript functions are used to perform different library operations such as adding, removing, borrowing, returning, and searching for books.
